# useTagGroup

`useTagGroup` lets people move between tags with the arrow keys and remove them
with the keyboard or a remove button.

## Quickstart

```jsx
import React from 'react'
import {useTagGroup} from 'downshift'

const fruits = ['Apple', 'Apricot', 'Banana']

export default function FruitTags() {
  const {items, getTagGroupProps, getTagProps, getTagRemoveProps} = useTagGroup(
    {initialItems: fruits},
  )

  return (
    <div {...getTagGroupProps({'aria-label': 'Selected fruit'})}>
      {items.map((fruit, index) => (
        <span key={fruit} {...getTagProps({index, 'aria-label': fruit})}>
          {fruit}
          <button
            type="button"
            {...getTagRemoveProps({index, 'aria-label': 'Remove'})}
          >
            ×
          </button>
        </span>
      ))}
    </div>
  )
}
```

Tab to the first tag, press Arrow Right to focus Apricot, then press Delete to
remove it.

## Using object items

The book example uses each title as the tag's label and calls `addItem` to put a
book back in the group.

[Open the book example in CodeSandbox][code-sandbox-basic-usage].

```jsx live
function TagGroupExample() {
  const books = [
    {id: 'book-1', author: 'Harper Lee', title: 'To Kill a Mockingbird'},
    {id: 'book-2', author: 'Lev Tolstoy', title: 'War and Peace'},
    {id: 'book-3', author: 'Fyodor Dostoevsky', title: 'The Idiot'},
    {id: 'book-4', author: 'Oscar Wilde', title: 'A Picture of Dorian Gray'},
    {id: 'book-5', author: 'George Orwell', title: '1984'},
    {id: 'book-6', author: 'Jane Austen', title: 'Pride and Prejudice'},
    {id: 'book-7', author: 'Marcus Aurelius', title: 'Meditations'},
    {
      id: 'book-8',
      author: 'Fyodor Dostoevsky',
      title: 'The Brothers Karamazov',
    },
    {id: 'book-9', author: 'Lev Tolstoy', title: 'Anna Karenina'},
    {id: 'book-10', author: 'Fyodor Dostoevsky', title: 'Crime and Punishment'},
  ]

  function TagGroup() {
    const initialItems = books.slice(0, 5)
    const {
      addItem,
      getTagProps,
      getTagRemoveProps,
      getTagGroupProps,
      items,
      activeIndex,
    } = useTagGroup({initialItems})
    const itemsToAdd = books.filter(book => !items.includes(book))

    return (
      <div>
        <div
          {...getTagGroupProps({'aria-label': 'books usage example'})}
          className="inline-flex gap-2 items-center flex-wrap p-1.5"
        >
          {items.map((item, index) => (
            <span
              className={`${
                index === activeIndex ? 'italic' : ''
              } border border-green-800 bg-green-600 px-1.5 mx-0.5 rounded-[10px] cursor-default hover:opacity-50 focus:bg-red-600 focus:border-red-800`}
              key={item.id}
              {...getTagProps({index, 'aria-label': item.title})}
            >
              {item.title}
              <button
                className="p-1 cursor-pointer border-0 bg-transparent"
                type="button"
                {...getTagRemoveProps({index, 'aria-label': 'remove'})}
              >
                &#10005;
              </button>
            </span>
          ))}
        </div>
        <div>Add more items:</div>
        <ul>
          {itemsToAdd.map(item => (
            <li key={item.id}>
              <button
                tabIndex={0}
                onClick={() => {
                  addItem(item)
                }}
                onKeyDown={({key}) => {
                  key === 'Enter' && addItem(item)
                }}
              >
                {item.title}
              </button>
            </li>
          ))}
        </ul>
      </div>
    )
  }

  return <TagGroup />
}
```

## Props used in examples

| Returned prop | Element | Purpose |
| --- | --- | --- |
| `getTagGroupProps` | `<div>` | Labels the group and handles keyboard navigation. |
| `getTagProps` | `<span>` | Makes the tag at `index` focusable by the hook. |
| `getTagRemoveProps` | `<button>` | Removes the tag at `index`. |
| `items` |  | The items to render as tags. |
| `activeIndex` |  | Index of the active tag. |
| `addItem` |  | Adds an item to the group. |

See the [useTagGroup API reference][use-tag-group-github] for all props and return values.
